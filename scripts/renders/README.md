# Product renders

The product images in `public/renders/` are 3D renders made with three.js (`render.html`), so every format is shown with the same lighting, angle and background.

To re-render: `npm i three@0.170` in a scratch folder with this file, `logo.png`, `logo-light.png` and `it.woff2` beside it, serve the folder on port 8765, then run `python3 shoot.py pharma folding rigid mailer shipping food bag labels`. Convert the PNGs to WebP (about 1100 px) into `public/renders/`.
